# Predicting-Life-Expectancy-Regression-problem.-
This is a socio-economic regression problem. You predict a country's life expectancy based on features like GDP, alcohol consumption, immunization coverage, BMI, and adult mortality.

Methodology:

Data Cleaning (Imputation using country medians).

Feature Engineering (Log transformation of GDP and Population to linearize relationships).

Feature Scaling (Z-score normalization).

Model: Multiple Linear Regression trained from scratch using Gradient Descent.
